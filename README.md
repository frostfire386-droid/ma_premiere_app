# ma_premiere_app – TP 01 à TP 04

## Mise en route (VS Code)
1. Dézipper, puis `File > Open Folder…` → `ma_premiere_app`
2. Terminal : `flutter create .`   (génère les dossiers web/android/… sans écraser `lib/`)
3. Terminal : `flutter pub get`
4. Choisir **Chrome** en bas à droite, puis **F5**
